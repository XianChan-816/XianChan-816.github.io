## 个人博客站点从零搭建

**目标**：免费静态个人站 + 本地后台改内容 + 一键发布。

**技术选型**（用户确认）：
- 托管：GitHub 仓库 + GitHub Actions → GitHub Pages（免费二级域名）
- 发布：本地后台 → git commit/push → Actions 自动部署
- 站点：纯静态 HTML/CSS/JS，无框架无构建

**结构**：
```
index.html          单页：Hero / 应用下载 / 关于 / 联系
assets/data.js      自动生成（window.SITE_DATA），页面直接读，避免 file:// CORS
assets/main.js      渲染 + 分类筛选 + 深浅色
assets/style.css    设计系统（浅/深双主题，青绿强调色 #0f766e）
data/site.json      内容唯一真源
data/backups/       每次保存自动备份，保留 30 份
data/.deploy.json   GitHub Token（gitignored）
admin/server.js     零依赖 Node 后台，127.0.0.1:8787
admin/ui.html       管理界面（资料 / 应用 / 发布设置 + 发布日志）
.github/workflows/deploy.yml  push main → Pages
```

**关键决策**：
- 内容数据化：`site.json` 为源，保存时同时生成 `assets/data.js`，页面用 `<script>` 引入而非 fetch —— 规避 file:// 的 CORS，双击也能打开
- 后台零依赖，用原生 node:http，不引入 Express
- 发布用 git（用户已有 git 2.55），push URL 临时注入 token，不落盘到 .git/config
- 仓库不存在时后台调 GitHub REST API 自动创建
- Actions 里 `rm -rf admin data package.json` 只发布站点文件
